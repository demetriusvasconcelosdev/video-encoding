# Video Encoding Microservice

A Go microservice that consumes video encoding jobs from RabbitMQ, downloads the source MP4 from Google Cloud Storage, converts it to MPEG-DASH with Bento4 and uploads the encoded files to an output bucket. The result of each job is published back to RabbitMQ, and messages that fail are routed to a dead letter exchange.

## Setting up the environment

To run in development mode, follow these steps:

* Copy `.env.example` to `.env`
* Run `docker-compose up -d`
* Open the RabbitMQ management UI and create a `fanout` exchange. It will be the `Dead Letter Exchange` that receives the messages that could not be processed.
* Create a `Dead Letter Queue` and bind it to the `Dead Letter Exchange` you just created. No routing key is needed.
* In the `.env` file, set the name of the `Dead Letter Exchange` in the `RABBITMQ_DLX` parameter
* Create a GCP service account with permission to write to Google Cloud Storage. Download its JSON credentials and save the file in the project root with exactly this name: `bucket-credential.json`

## Running

To run the encoder, execute `make server` inside the container. Example:

```
docker exec encoder_app_1 make server
```

`encoder_app_1` is the name of the container generated by docker-compose.

## Input message format

For a message to be parsed by the encoder, it must arrive in the following JSON format:

```
{
  "resource_id": "my-resource-id-can-be-a-uuid-type",
  "file_path": "video.mp4"
}
```

* `resource_id`: the ID of the video you want to convert. It is a string.
* `file_path`: the full path of the MP4 video inside the input bucket.

## Output message format

### Successful processing

For each processed video, the encoder publishes the result to an exchange (configured in `.env`).

When the job completes successfully, the JSON payload is:

```
{
    "job_id":"bbbdd123-ad05-4dc8-a74c-d63a0a2423d5",
    "output_bucket_path":"my-output-bucket",
    "status":"COMPLETED",
    "video":{
        "encoded_video_folder":"b3f2d41e-2c0a-4830-bd65-68227e97764f",
        "resource_id":"aadc5ff9-0b0d-13ab-4a40-a11b2eaa148c",
        "file_path":"video.mp4"
    },
    "Error":"",
    "created_at":"2020-05-27T19:43:34.850479-04:00",
    "updated_at":"2020-05-27T19:43:38.081754-04:00"
}
```

`encoded_video_folder` is the folder that holds the converted video.

### Processing error

When an error happens during processing, the JSON payload is:

```
{
    "message": {
        "resource_id": "aadc5ff9-010d-a3ab-4a40-a11b2eaa148c",
        "file_path": "video.mp4"
    },
    "error":"Reason for the error"
}
```

The encoder also sends the original message that failed to a dead letter exchange.
Configure the desired DLX in the `.env` file through the `RABBITMQ_DLX` parameter.
